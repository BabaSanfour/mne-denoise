**DSS**:
- ``DSS`` gained an optional ``whiten`` mode (with an optional ``noise_cov``) for jointly decomposing multiple data channel types (e.g. mag + grad + eeg) in a single run. When enabled, the data is whitened before the bias/covariance step and un-whitened on reconstruction, so channels with different physical units no longer contaminate one another; without a ``noise_cov`` a per-channel diagonal whitener is estimated from the data. Estimators previously isolated a single homogeneous channel type, and the mixed-type warning now also points at ``whiten=True`` (Issue #37).

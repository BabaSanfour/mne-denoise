**Visualization**:
- Added an interactive component-selection GUI, ``mne_denoise.viz.plot_component_selector`` (returning a ``ComponentSelector``), modelled on :func:`mne.viz.plot_ica_components`. It plots each component's spatial pattern, time course and PSD, lets the user click a component to toggle whether it is excluded from the clean output, and shows a live before/after preview (global field power and PSD) of the reconstruction. It is estimator-aware: for ``DSS`` the non-excluded signal components are reconstructed, while for ``ZapLine`` the excluded noise components are removed. A convenience ``DSS.plot_components(data, interactive=True, preview=True)`` method (inherited by ``ZapLine``) is also provided, mirroring MNE's ICA API; ``plot_sources`` is reserved for a future scrollable browser (Issue #38).

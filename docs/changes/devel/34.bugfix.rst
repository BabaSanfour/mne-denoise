**Core**:
- All denoising estimators (``ZapLine``, ``ICanClean``, etc.) now automatically select and fit only a single homogeneous MNE channel type (e.g., exclusively MEG magnetometers, or exclusively EEG) when passed mixed-channel ``Raw`` or ``Epochs`` objects. This prevents cross-contamination of components between sensors with vastly different physical units and correctly handles objects with reference or stimulus channels. Non-target channels are seamlessly restored to the output object unchanged.
- Functions like ``plot_psd_comparison`` now automatically pick the primary channel type (e.g., 'mag', 'grad', 'eeg') instead of requiring manual selection. This uses the new centralized ``_get_homogeneous_picks`` logic, bringing the visualization API in line with the auto-picking behavior of the denoising estimators.
- Fixed PSD visualization functions occasionally emitting ``Data has no positive values`` matplotlib warnings by safely clipping computed power spectra to a small positive floor.

**ZapLine**:
- Fixed ``ZapLine`` with ``n_remove='auto'`` returning 0 components on high-channel-count MEG data with many co-equal line-noise components (e.g., CTF 275-channel recordings). The iterative outlier selector assumes 1-2 dominant components and fails when several DSS eigenvalues are similar; we now layer a log-space knee detector on top of it and use the larger of the two counts (Issue #34).
- Added ``mne_denoise.dss.utils.detect_eigenvalue_knee`` and ``auto_select_components_robust`` helpers, plus optional ``knee_rel_floor`` and ``knee_min_ratio`` parameters to ``ZapLine`` for tuning.

**DSS**:
- ``compute_dss`` now treats the baseline covariance variance check as relative to the data scale instead of rejecting valid SI-unit MEG covariances. It also emits a warning when the ``reg``-based rank reduction discards more than 75% of channels; the message points users at channel normalization, lowering ``reg``, or fitting homogeneous channel types separately.
